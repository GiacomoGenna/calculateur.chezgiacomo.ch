# calculateur.chezgiacomo.ch

⛔ **Ce dépôt ne sert plus le calculateur.** Il a été rapatrié le 2026-08-19 dans
le site principal, sur https://chezgiacomo.ch/calculateur, où il vit maintenant
en React dans `qg-marketing/ateliers/chez-giacomo/site/`.

Le sous-domaine `calculateur.chezgiacomo.ch` pointe désormais sur le VPS
(`179.237.85.41`), et Caddy y répond par une redirection 301 permanente.

## Pourquoi ce dépôt existe encore

Deux raisons, et aucune n'est le sentiment :

1. **Il porte l'historique** des 4 commits d'origine et la version de référence
   du calculateur, qui a servi à vérifier le portage ligne par ligne.
2. **Le talon `index.html` est une ceinture et des bretelles** : si le DNS
   repointait un jour vers GitHub Pages, par erreur ou par restauration, le
   visiteur atterrirait quand même au bon endroit au lieu de voir une version
   figée du calculateur.

⚠️ **Le fichier `CNAME` a été retiré**, sinon GitHub Pages continue de
revendiquer le nom de domaine.
